# SyntaxWear - Loja de Tênis e Sneakers

## Sobre o projeto

`SyntaxWear` é um site de e-commerce one-page para venda de tênis e sneakers. O projeto foi construído com HTML e CSS puro, seguindo uma estrutura modular de estilos para facilitar manutenção e personalização.

## Conteúdo da página

- `index.html` — página principal do site.
- `css/reset.css` — reset de estilos básicos para normalizar o layout.
- `css/variables.css` — variáveis CSS e import de fonte do Google Fonts.
- `css/base.css` — estilos gerais, botões e tipografia.
- `css/components/header.css` — estilo do cabeçalho e navegação.
- `css/components/hero.css` — estilo da seção hero/banner.
- `css/components/product-category.css` — cards de categorias de produtos.
- `css/components/product-grid.css` — grid de destaque dos produtos.
- `css/components/footer.css` — estilos do rodapé.
- `js/` — pasta reservada para scripts JavaScript (atualmente vazia).
- `images/` — imagens usadas no site, incluindo banners, ícones, logo e fotos de produtos.

## Recursos e funcionalidades

- Layout responsivo com adaptação para dispositivos móveis.
- Menu mobile com toggle para navegação em telas menores.
- Seção hero com chamada para ação e botões de navegação.
- Cards de categorias com imagens de produtos.
- Grid principal de produtos com destaque visual.
- Rodapé com newsletter, redes sociais e links de navegação.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Edite os arquivos CSS em `css/` para ajustar cores, fontes e layout.
3. Substitua as imagens em `images/` para atualizar o conteúdo visual.
4. Adicione scripts em `js/` caso precise de interatividade adicional.

## Personalização

- Troque a imagem de fundo do hero em `css/components/hero.css`.
- Atualize as categorias e produtos no `index.html`.
- Ajuste a tipografia em `css/variables.css`.
- Adicione mais regras responsivas em `css/base.css` ou nos arquivos de componentes.

## Observações

- O projeto não depende de bibliotecas externas além da fonte Google Fonts.
- O diretório `js/` está disponível para futuramente incluir scripts de carrinho, animações ou formulários dinâmicos.
